# IPL Match Data Analysis Using Python

## Project Overview
This project analyzes IPL 2022 match data using Python and data visualization libraries. It explores team performance, toss decisions, player achievements, match venues, innings scores, and winning margins.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Key Analysis
- Team-wise match wins
- Toss decisions and match results
- Player of the Match awards
- Highest individual and team scores
- Venue-wise match distribution
- Innings score analysis
- Winning margin analysis
- Monthly match distribution
- Data cleaning and validation

## Key Findings
- Total matches analyzed: 74
- Gujarat recorded the highest number of wins: 12
- Rajasthan recorded 10 wins
- Fielding was selected as the toss decision 59 times
- Kuldeep Yadav received 4 Player of the Match awards
- Highest individual score: 140
- Highest first-innings team score: 222

*These findings apply only to the dataset used in this project.*

## How to Run
1. Open the notebook in Google Colab.
2. Upload the IPL dataset CSV file when prompted.
3. Run the notebook cells in order.
4. Review the charts and analysis results.
